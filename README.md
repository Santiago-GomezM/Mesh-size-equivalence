# Mesh-size-equivalence

This repository contains MATLAB functions used to compute the probability of passage of
ellipsoidal particles through openings of different geometries (rectangular, square,
hexagonal, circular), as presented in the associated scientific article.

The code implements a fully three-dimensional orientation framework and evaluates
single-attempt and multi-attempt passage probabilities based on projected ellipses
and geometric admissibility conditions.
