The data included in this folder are provided in Microsoft Excel format (.xlsx).

The Excel file is organized into multiple worksheets:

The first worksheet contains the measured dimensions of the largest fragments collected from the blasting operations. The subsequent worksheets contain the measurements of fragments belonging to the 60/25 mm size fraction for each of the 16 blasts.

The blasts are identified as follows: N1–N4 Blasts from the north side of the trench, and S1–S12 Blasts from the south side of the trench.

Each worksheet corresponding to a specific blast includes the dimensional measurements of the fragments collected for that particular blasting event.
